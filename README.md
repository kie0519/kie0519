**AI FDE · Agent Systems Architect**

> 我研究的不是如何让机器更像人。  
> 我更关心，人的意图如何在机器中获得可靠的行动。

我的工作位于三条边界的交汇处：业务决定为何出发，产品定义何为抵达，工程回答这段路是否真实存在。

很多 AI 项目始于一个过早的答案——一个 Agent、一条 Workflow、一次模型接入。而我通常从答案之前开始：重新辨认问题，找到值得被自动化的部分，建立结果成立的标准；再从答案之后继续：组织上下文，配置能力与边界，让系统行动，并对它的结果保持怀疑。

这是一种从模糊走向清晰、再从清晰走向现实的工作。

---

### The distance between intent and action

一个 Agent 是否真正成立，不取决于它说得多像人，而取决于三个问题。

**它知道什么。**  
上下文不是信息的总和，而是对“此刻什么重要”的判断。

**它能够做什么。**  
每一种能力都同时意味着一种权限；工具越多，边界越需要被认真设计。

**我们如何知道它做对了。**  
无法被评价的智能，只是一场印象。Evals 不是验收的最后一步，而是产品定义本身。

Context、Capability、Evaluation——它们共同决定一次模型调用能否成为一个系统。

---

### 问知言行

**问**，是对欲望的校准。  
**知**，是对世界的辨认。  
**言**，是让认知穿过语言的窄门。  
**行**，是让选择接受现实的检验。

在 AI 的语境里，Prompt 从来不只是一段指令。它是人的理解与机器的行动之间，那层可以被设计的界面。

问得足够深，才知道什么是对的；理解足够清楚，才知道应该告诉机器什么；表达足够准确，行动才可能接近意图。

开头与结尾都指向“所欲”。不同的是，最初的欲望仍然混沌，最后的行动已经成为选择。

---

### Current practice

目前，我在北京从事 AI FDE 与 Agent Engineering，持续探索能够在真实环境中工作的 Agent 系统：它们如何获得上下文，如何使用工具，如何跨越长程任务，如何与其他 Agent 协作，又应当在哪些时刻把判断交还给人。

我对模型能力保持乐观，对系统可靠性保持谨慎。
